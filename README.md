# Gaurav Tailor Portfolio

Premium static portfolio for Gaurav Tailor, focused on SOC analysis, threat detection, DFIR practice, and the threat hunter journey.

## Files

- `index.html` - main portfolio page
- `styles.css` - visual design, responsive layout, and dark cyber theme
- `script.js` - scroll reveal and subtle pointer lighting
- `assets/cyber-hero.png` - generated premium cybersecurity hero image

## Preview Locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## Share It Online

### Fastest Option: Netlify Drag And Drop

1. Go to `https://app.netlify.com/drop`.
2. Drag the whole `gaurav-portfolio` folder onto the page.
3. Netlify will publish it and give you a public share link.
4. You can rename the site in Netlify site settings.

### Best Long-Term Option: GitHub Pages

1. Create a GitHub repository named `gaurav-portfolio`.
2. Upload all files from this folder to the repository root.
3. Open the repository settings.
4. Go to Pages.
5. Set the source to the main branch and root folder.
6. Save, then wait for GitHub to publish the public site URL.

### Vercel

1. Create a Vercel project from the repository.
2. Keep the framework preset as Other.
3. Use the project root as the output directory.
4. Deploy.
